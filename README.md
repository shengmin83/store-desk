# Store Desk PWA

Free static PWA deployment for GitHub Pages.

## Publish
1. Create a **public** GitHub repository, e.g. `store-desk`.
2. Upload all files in this folder to the repository root.
3. GitHub → **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. Wait for deployment. Open the generated `https://YOUR-USERNAME.github.io/store-desk/` URL in Safari.
7. iPhone: **Share → Add to Home Screen → Add**.

The app is static and requires no paid hosting. GitHub Pages supports public repositories on GitHub Free and serves `github.io` sites over HTTPS.
